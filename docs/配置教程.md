# 配置教程：从零到跑通

**中文** | [English](setup-guide.md)

本教程以 **ZCode 客户端**（3.x，桌面版 / CLI 均可）为例写最细的路径；其他客户端的差异见第 8 节。
全程约 10 分钟，除 Exa 注册（可选）外不需要任何账号。

---

## 0. 前置条件

| 项 | 要求 |
|---|---|
| Agent 客户端 | ZCode 3.x（本仓库在其上验证）；Claude Code / Cursor 等见第 8 节 |
| 网络 | 能访问 `mcp.exa.ai`（中国大陆需要代理） |
| Exa 账号 | 可选。匿名模式可用但有限流；注册后额度更稳定（免费） |
| Node.js | 仅在使用浏览器兜底（`playwright-cli`）或 `mcp-remote` 时才需要 |

---

## 1. 注册 Exa 并拿到 API key（推荐，约 5 分钟）

1. 打开 <https://dashboard.exa.ai> 注册（Google / GitHub 账号均可）
2. 左侧菜单 **API Keys** → **Create Key**
3. 复制 key（UUID 形式，形如 `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`），先存到密码管理器

**额度与价格**（以 <https://exa.ai/pricing> 为准）：

| 项目 | 说明 |
|---|---|
| 新账号赠金 | $20（约 2800 次搜索） |
| 免费档 | 每月再送 $10（约 1400 次搜索） |
| 搜索 | $7 / 千次（每次含最多 10 条结果；超出 $1 / 千条） |
| 抓正文 | $1 / 千页（text / highlights / summary 分别计） |
| 高级搜索 | 与普通搜索同价；用不用过滤参数一个价 |
| `agent_run`（可选） | 按次计费 $0.012–$1（多步研究 Agent，免费档不可用） |

> 个人日常调研基本用不完免费额度。

## 2. 配置 Exa MCP

### 2.1 配置文件位置

| 作用域 | 路径 | 生效范围 |
|---|---|---|
| 用户级（推荐） | `~/.zcode/cli/config.json` | 所有工作区 |
| 工作区级 | `<项目>/.zcode/config.json` | 仅该项目 |

### 2.2 写入配置

打开 `~/.zcode/cli/config.json`，在 `mcp.servers` 下加入 `exa`（与其他已有条目并列）：

```json
{
  "mcp": {
    "servers": {
      "exa": {
        "type": "http",
        "url": "https://mcp.exa.ai/mcp?tools=web_search_exa,web_fetch_exa,web_search_advanced_exa",
        "timeoutMs": 60000,
        "headers": {
          "x-api-key": "YOUR_EXA_API_KEY"
        }
      }
    }
  }
}
```

**匿名模式**（不填 key）：删掉 `headers` 整个字段即可。

> 仓库里的 `examples/config/zcode-mcp.json` 是同一份模板，可直接参考。

### 2.3 三个必踩的坑

1. **键名是 `mcp.servers`（嵌套），不是顶层 `mcpServers`**  
   ZCode 的配置文件用嵌套结构；`mcpServers` 是 `.agents/mcp.json` 兼容层的格式。写错位置 = 服务器不出现。

2. **schema 严格，多写字段会被静默丢弃**  
   http 型只认 `type` / `url` / `headers` / `enabled` / `timeoutMs` 等有限字段。多写一个未知键，整个 server 会被丢掉（设置页里看不到，也不报错）。

3. **`?tools=` 会"替换"默认工具列表，不是追加**  
   默认只有 `web_search_exa`、`web_fetch_exa`。想用高级搜索必须显式列全：  
   `?tools=web_search_exa,web_fetch_exa,web_search_advanced_exa`  
   （`agent_run` 需要 OAuth 或 API key，且免费档不可用。）

### 2.4 重启并检查

1. 新开一个会话（MCP 在会话启动时连接）
2. 打开 **设置 → MCP**，`exa` 应为 connected
3. 让 Agent 查一个需要联网的问题，观察它是否调用 `web_search_exa`

## 3. 安装规则文件（AGENTS.md）

```bash
# 用户级（推荐：所有工作区生效）
cp AGENTS.md ~/.zcode/AGENTS.md

# 或者工作区级（只对某个项目生效）
cp AGENTS.md <项目根目录>/AGENTS.md
```

**它是什么**：常驻判断规则，每个会话启动时加载。内容包括五问总则、七类落点、不搜清单、查证分档、硬底线（含冲突裁决）。约 1.3k 字符，常驻成本可忽略。

**注意**：如果目标位置已有 AGENTS.md，**不要直接覆盖**——先把这套规则合并进你原有的个人规则（它只占"联网搜索"这一节）。

## 4. 安装技能（web-research）

```bash
mkdir -p ~/.zcode/skills/web-research
cp skills/web-research/SKILL.md ~/.zcode/skills/web-research/
```

| 作用域 | 路径 |
|---|---|
| 用户级 | `~/.zcode/skills/web-research/SKILL.md` |
| 工作区级 | `<项目>/.zcode/skills/web-research/SKILL.md` |

- 技能在**会话启动时**进入可用清单，装完要新开会话。
- 同名技能多处存在时，用户级优先（工作区副本会被遮蔽）。

### 4.1 浏览器兜底工具（可选）

技能第 5 步把浏览器兜底拆成两个工具，判据是"这个页面值不值得用你的真实身份打开"。两个都不装也能跑通前两层，只是第③层没得用。

```bash
# ③a 需要登录态的站点：ego lite
# 从 https://lite.ego.app/ 下载安装，首次启动完成 onboarding（会注册 ego-browser 命令）

# ③b 可疑站点、需要隔离：playwright-cli
npm install -g @playwright/cli@latest
playwright-cli install --skills
```

- 如果 `playwright-cli install --skills` 只写入了 `.claude/skills/`，把该目录下的 `playwright-cli` 整个拷到 `~/.zcode/skills/`，ZCode 才认。
- 分工与理由见 README「浏览器兜底为什么拆成两个工具」；手头只有 Playwright MCP 也可以直接替代，流程逻辑不变。

## 5. 验证整条链路

新开会话，按下表逐项打勾：

| # | 检查 | 怎么做 | 预期 |
|---|---|---|---|
| 1 | MCP 已连接 | 设置 → MCP | `exa`: connected |
| 2 | 搜索工具可用 | 问"帮我查一下今天有什么 AI 新闻" | 调用了 `web_search_exa` |
| 3 | 触发词生效 | 输入"联网搜索 <某个时效性问题>" | 按完整流程执行（粗搜 → 抓全文 → 第二轮） |
| 4 | 分档生效 | 问一个单点事实（如"某公告的文号是多少"） | 一次检索收工，不跑全流程 |
| 5 | 输出纪律 | 看结论 | 附来源链接 + 标注「已证实 / 未证实 / 时效未知」 |
| 6 | 人机分工 | 问"XX 值不值得用" | 提醒你这属于评价类，建议人工搜 |

## 6. 常见问题（排错表）

| 现象 | 原因 | 解决 |
|---|---|---|
| 工具列表没有 `exa` | 配置未生效 / 没新开会话 | 检查是不是写在 `mcp.servers` 下；新开会话；必要时重启客户端 |
| 设置页显示 `failed` | schema 不合法（多写了字段）或 url 写错 | 对照 2.2 的 JSON 精简字段 |
| 搜索卡住后超时 | 免费额度用尽（429 被客户端吞掉） | 加 `x-api-key` |
| 返回 429 | 额度 / 限流 | 注册拿 key，或等每月额度刷新 |
| 中国大陆连不上 | 网络不可达 | 开代理；终端里设 `HTTPS_PROXY` |
| 高级搜索调不到 | url 没带 `?tools=` 或没列全 | 按 2.2 的 url 写全三个工具 |
| 规则没生效 | AGENTS.md 放错位置 / 同名文件被遮蔽 | 用户级优先；确认路径正确后新开会话 |
| 技能不出现 | 没新开会话 / 目录层级不对 | 确认是 `skills/web-research/SKILL.md`（两层目录） |

## 7. 可选：硬触发（hook + 命令）

**默认不需要。** 对照实验显示软触发与硬触发在质量上打平，软触发成本更低；硬触发只在"必须保证触发"时有价值。

### 7.1 手动命令（建议先试这个）

把 `examples/commands/research.md` 复制到 `~/.zcode/commands/`，之后：

```
/research 2026年出口退税最新公告
```

命令会把完整流程作为指令展开，强制走完全流程。成本：命令列表里一行描述。

### 7.2 关键词 hook（自动化，可选）

1. 复制脚本：

   ```bash
   mkdir -p ~/.zcode/hooks
   cp examples/hook/research-trigger.py ~/.zcode/hooks/
   ```

2. 在 `~/.zcode/cli/config.json` 顶层（与 `mcp` 平级）加入：

   ```json
   "hooks": {
     "enabled": true,
     "events": {
       "UserPromptSubmit": [
         {
           "matcher": "联网搜索",
           "hooks": [
             {
               "type": "process",
               "command": "C:/Users/你/AppData/Local/Programs/Python/Python312/python.exe",
               "args": ["C:/Users/你/.zcode/hooks/research-trigger.py"],
               "timeoutMs": 10000
             }
           ]
         }
       ]
     }
   }
   ```

3. 把 `command` / `args` 换成你机器上的真实路径：
   - Windows：用 `python.exe` 的绝对路径（`where python` 查）
   - macOS / Linux：`/usr/bin/python3` 或 `python3`
4. 新开会话，发一条含「联网搜索」的消息验证

**注意**：

- `hooks.enabled: true` 是必须的（配置文件的 hook 默认关闭）
- matcher 是**大小写敏感的正则**，`联网搜索` 四个字连在一起才会命中
- 脚本输出必须是合法 JSON（本仓库的脚本已处理，输出为编码无关的 ASCII）

### 7.3 撤销硬触发

删掉配置里的 `hooks` 块、删除 `~/.zcode/hooks/research-trigger.py` 与 `~/.zcode/commands/research.md` 即可。

## 8. 适配其他客户端

规则与技能是通用的，只需改 MCP 配置：

| 客户端 | MCP 配置位置 | 关键写法 |
|---|---|---|
| **ZCode** | `~/.zcode/cli/config.json` | 嵌套 `mcp.servers`；`"type": "http"` + `url` |
| **Claude Code** | 项目根 `.mcp.json` | 顶层 `mcpServers`；`"type": "http"` + `url`（或 `claude plugin install exa@claude-plugins-official`） |
| **Cursor** | `~/.cursor/mcp.json` | `mcpServers`；键名是 `url` |
| **VS Code** | `.vscode/mcp.json` | 官方一键安装，或手写 `url` |
| 不支持远程 MCP 的客户端 | —— | `npx -y mcp-remote https://mcp.exa.ai/mcp` |
| 本地安装 Exa MCP | —— | `npx -y exa-mcp-server`，环境变量 `EXA_API_KEY` |

规则文件：ZCode 是 `AGENTS.md`；Claude Code 是 `CLAUDE.md`（内容相同，改文件名即可）。
技能目录：两家的 `skills/<name>/SKILL.md` 结构一致。

## 9. 卸载 / 回滚清单

本仓库只做**加法**，卸载 = 删掉你加的东西：

| 改动 | 位置 |
|---|---|
| 规则文件 | `~/.zcode/AGENTS.md`（只删"联网搜索"一节也可） |
| 技能 | `~/.zcode/skills/web-research/` |
| MCP 配置 | `~/.zcode/cli/config.json` 里的 `mcp.servers.exa` |
| 可选命令 | `~/.zcode/commands/research.md` |
| 可选 hook | `~/.zcode/cli/config.json` 的 `hooks` 块 + `~/.zcode/hooks/research-trigger.py` |

建议改动前先备份 `config.json` 和 `AGENTS.md`。

## 10. 安全

- **不要提交 API key**：key 只写在本地用户配置（`~/.zcode/cli/config.json`）里。本仓库不含任何密钥，`.gitignore` 已排除常见本地配置文件。
- key 泄露后到 <https://dashboard.exa.ai> 吊销并重建。
- 规则里的"人机分工"是为了防 AI 在评价类问题上过度自信，但它不构成专业意见——健康 / 法律 / 金融问题请以权威来源为准。
